Questions

Is NexusHub free?

Yes. NexusHub is free, with no ads and no in-app purchases.

What do I need to install it?

Windows 10 or 11 and Python 3.12 or newer (free from python.org; tick “Add Python to PATH”). Then run install.bat from the download. It installs everything else automatically.

Will it break my Windows taskbar?

No. The Nexus Dock only hides the Windows taskbar. Switching the dock off, quitting NexusHub, or even a crash brings the normal taskbar straight back.

Why does NexusHub ask for Google Drive access?

Only if you choose to sign in. NexusHub uses Drive's private app-data folder to back up your profiles so you can use them on another PC. It can't see any of your other Drive files.

Does it work in games?

Yes. Hotkeys work in fullscreen games. The crosshair and stats overlay work in borderless or windowed mode. Game Mode switches on by itself when you start a game.

Is it safe to use the crosshair in online games?

The crosshair only draws on your screen and never touches the game, but some competitive games have strict rules. Check your game's rules before using it in ranked matches.

How do I uninstall it?

Settings → “Quit NexusHub completely”, turn off “Start with Windows”, then delete the NexusHub folder. Your settings live in %APPDATA%\NexusHub and can be deleted too.
